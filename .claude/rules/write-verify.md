# 쓰기 규칙 검증 규칙 (앱 `app/engine/figma-write.js`)

2026-11-02 SVOD WEB "피쳐링셀 케이스" 링크 뱃지가 PR #51·#52 두 번 연속 비어 있던 일에서 나온 규칙. 경위는 `.claude/lessons_log.md` 같은 날짜 항목.

- **사용자가 가리킨 실제 노드로 필터를 따라간다.** 반영 코드에 "어떤 노드를 고칠지" 조건을 넣거나 바꾸면, PR 전에 그 조건을 사용자가 링크로 가리킨 실제 노드(REST `GET /v1/files/:key/nodes?ids=…`)와 그 조상에 손으로 대입해 통과하는지 확인한다. 가짜 시험 데이터 통과만으로는 PR을 올리지 않는다.
- **요청에 없는 가드는 넣지 않는다.** "바뀐 섹션만", "화면 속은 제외" 같은 범위 제한은 사용자가 말하지 않았으면 넣지 않는다. 넣어야 한다고 판단되면 그 가드가 쓰는 데이터의 뜻(예: `coreScreenIds`는 섹션 바로 아래 프레임 전부 = 설명 카드도 포함)을 코드에서 확인한 뒤 넣는다.
- 같은 요청으로 "여전히 안 됨"이 두 번째로 오면 코드를 고치기 전에 실제 파일에서 그 노드가 걸러진 지점을 먼저 찾아 보고한다.
