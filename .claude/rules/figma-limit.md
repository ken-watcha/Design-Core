# Figma 읽기 20KB 한도 규칙 (앱 `app/`)

2026-10-14 [Core] SVOD (홈) 브랜치 확인에서 화면 차이 비교가 56KB를 돌려줘 멈춘 일에서 나온 규칙.

- `use_figma`는 한 번에 20KB(20,480바이트)까지만 돌려준다. 앱이 Figma에서 돌리는 코드는 **돌려주는 양이 화면 수·요소 수에 비례하면 안 된다.**
- 목록을 돌려주는 코드는 Figma 쪽에서 바이트를 세어 14KB쯤에서 멈추고 남은 id를 `rest`로 돌려준다. 앱은 `readInParts`(`app/engine/figma-find.js`)로 남은 것만 다시 부른다.
- 요소 목록처럼 큰 내용은 그대로 보내지 말고 해시·개수로 줄여 비교한 뒤, 필요한 것만 이름으로 다시 받는다.
- 새 읽기 코드를 만들면 `app/test/limit.test.js`(아주 큰 가짜 Core·문서)에 넣어 한도 아래인지 시험한다. 실제 Figma에서 확인한 크기 예: SVOD (홈) 화면 1장 요소 600~1,500개, 마스터 화면 41장.
