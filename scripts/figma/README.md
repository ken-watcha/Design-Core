# Figma 읽기 스크립트 모음

모두 **읽기 전용**이다. Figma MCP의 `use_figma` 도구에 코드 그대로 붙여넣고 `fileKey`만 지정하면 된다.
파일이 Figma 앱에 열려 있지 않아도 동작한다 (2026-09-09 확인).

| 스크립트 | 하는 일 | 언제 쓰나 |
|---|---|---|
| `list-pages.js` | 페이지 목록(ID·이름) | 새 Core 파일 링크를 받았을 때 맨 먼저 |
| `walk-page.js` | 한 페이지의 섹션·프레임 골격 (깊이 제한) | 마스터/플로우 페이지 수록 화면 파악 |
| `label-texts.js` | 설명 바(스크린 설명 컴포넌트) 제목·색상 | 화면 묶음 제목(대분류/케이스/크기) 파악 |
| `link-card.js` | 스펙 링크 카드의 텍스트·하이퍼링크 | 기준 문서 위치 확인, 기준 정보 기입 여부 확인 |

## 주의

- `use_figma`는 호출마다 첫 페이지에서 시작하므로 스크립트 안에서 `setCurrentPageAsync`를 **한 번만** 호출한다. 여러 페이지를 볼 때는 페이지마다 호출을 나눈다 (병렬 가능).
- 큰 페이지(플로우 페이지)는 `MAXD`를 2로 낮추고 `MIN_W`를 300으로 올려 라벨·화살표를 걸러낸다.
- 쓰기 스크립트(복제·배치·라벨 교체)는 Ken 승인 뒤에만 만들고, 만들면 이 폴더가 아니라 `scripts/figma-write/`에 둔다 (아직 없음).
