Ken이 보낸 "모든 Core 파일" 14개에 없는 것도 이 때문이다. → 색인에서 Core 목록에서 빼고 "관련 파일(프로젝트 문서)"로 옮겼다.

**대안 두 개와 버린 이유**

- 보관함 Core 안에 넣기(노션 개편안의 후보): 보관함은 "내가 모은 것"(보고싶어요·시청·구매), 스텝메이드는 "왓챠가 골라 준 것"(에디토리얼 큐레이션) → 소유권 규칙 "목적지 소유"로 보면 다른 목적지.
