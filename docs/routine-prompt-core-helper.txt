절대 규칙: Figma 쓰기는 그 프로젝트 파일의 브랜치 "Core 도우미"에만, 실행 승인 없이는 어떤 파일에도 쓰지 않는다. Core 본 파일·다른 Core 파일에는 쓰지 않는다. 쓰기 전 브랜치에 Named version을 저장한다. 화면은 새로 만들지 말고 프로젝트 문서의 프레임을 그대로 복제해 분류만 하고, 복제 뒤 원본 대조로 차이 0을 확인한다. 문서의 섹션을 하나도 빠뜨리지 않는다(수록 대조표). 막힌 도메인이 있으면 우회하지 말고 결과에 도메인 이름을 적는다. 폴더 조회(projects:read)는 불가이니 시도하지 않는다.
