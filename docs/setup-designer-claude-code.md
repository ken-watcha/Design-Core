# 디자이너용 설치 안내 — 내 컴퓨터에서 Core 도우미 쓰기 (형태 A)

> 2026-09-14 Ken 결정. 설치할 것은 Claude Code 데스크톱 앱 하나. 도우미의 규칙(지침서·색인·절차)은 이 저장소에 있어서, 폴더를 열면 그대로 붙는다. 앱을 따로 만들지 않는다.
> 근거 문서: https://code.claude.com/docs/en/desktop-quickstart · https://code.claude.com/docs/en/mcp · https://code.claude.com/docs/en/skills

1. Claude Code 데스크톱 앱 설치 (맥) → 회사 Claude 계정으로 로그인
2. 이 저장소 폴더를 내 컴퓨터에 내려받기
3. 앱에서 그 폴더 열기 → 처음 한 번 "Figma 연결 허용" → 브라우저에서 Figma 로그인
4. 채팅에 프로젝트 문서 링크 붙여넣기 → 도우미가 판별·Δ 제안 → 내가 "진행" → 브랜치에 반영

## 2. 처음 한 번 설정 (10분)

1. 앱 실행 → **Code** 탭 → 환경 **Local** → **Select folder** → 내려받은 `Design-Core` 폴더 선택.
2. 첫 세션이 열리면 "이 프로젝트의 외부 연결(figma)을 허용할까요?" 하고 묻는다 → **허용**. 저장소 안 `.mcp.json`이 Figma 연결 주소를 미리 적어 둔 것이라 주소를 손으로 넣을 일은 없다.
3. 채팅창에 `/mcp` 입력 → `figma` → **Authenticate** → 브라우저가 열리면 Figma 로그인·허용. 한 번 하면 다음부터 자동.
4. 확인: 채팅에 "Figma 연결 확인해 줘(whoami)"라고 치면 내 Figma 계정 이름이 나와야 한다.

Notion(요청 표 사본)은 선택이다. 필요하면 같은 방법으로 `/mcp`에서 Notion을 추가한다.

## 3. 쓰는 법

채팅에 이렇게 쓴다. 코드나 명령어는 필요 없다.

```
이 프로젝트 문서를 Core에 반영해 줘: https://www.figma.com/design/<파일키>/...?node-id=...
프로젝트: <이름> · 배포: <YYYY.MM> · 담당: <내 이름>
```

도우미가 하는 순서(지침서 `.claude/skills/core-file-helper/SKILL.md`):
1. 문서를 읽기만 하고 → 어느 Core의 어느 부분인지 판별(유형 A 기존 갱신 / B 여러 Core / C 새 Core) → Δ 목록과 **수록 대조표**(문서의 모든 섹션이 어디로 갔는지)를 보여 준다.
2. 여기서 멈추고 나에게 묻는다. 내가 **"진행"**이라고 하면 실행한다.
3. 실행은 **그 파일의 브랜치 "Core 도우미"**에만 쓴다. 브랜치는 내가 Figma에서 미리 만든다(도우미는 브랜치를 못 만든다). Core 본 파일에는 쓰지 않는다.
4. 끝나면 결과 링크(node-id 포함)를 준다. 브랜치를 보고 마음에 들면 내가 머지한다.

지켜지는 원칙: 화면은 새로 그리지 않고 문서의 프레임을 **그대로 복사**해 분류만 한다(복사 뒤 원본과 대조해 차이 0). 문서 섹션은 하나도 빠뜨리지 않는다.

## 4. 클라우드 도우미(Routine)와의 차이

| | 내 컴퓨터(형태 A) | 클라우드(요청함 + Routine) |
|---|---|---|
| 누가 실행 | 내 Figma 계정 | Ken 계정 |
| 시작 | 채팅에 링크 | 요청함 페이지에 링크 + 버튼 |
| 확인 단계 | 있음 — 도우미가 묻고 내가 "진행" | 없음 — 버튼이 곧 실행 |
| 기록 | 채팅에 남음 | 요청함 `logs` + Notion 표 |
| 폴더·REST 읽기 | 안 됨(토큰 없음) — Figma 연결로만 읽음 | Design-Core 환경 토큰으로 됨 |

같은 규칙(저장소)을 쓰므로 결과는 같다. 둘 다 써도 된다.

## 5. 규칙이 바뀌면

규칙은 저장소 `main`에 있다. Ken이 지침서를 고쳐 올리면, 각자 폴더를 다시 내려받는다(ZIP 다시 받기 또는 GitHub Desktop **Pull**). 앱은 폴더의 최신 파일을 그대로 읽는다. 앱을 다시 설치할 일은 없다.

## 6. 막힐 때

- "Figma 도구가 없다" → `/mcp`에서 figma가 연결됐는지 본다. 끊겼으면 Authenticate 다시.
- "권한이 없다(403)" → 그 Figma 파일에 내가 편집 권한이 있는지 본다. 브랜치 쓰기는 편집 권한이 필요하다.
- 도우미가 "브랜치 'Core 도우미'를 만들어 주세요"라고 하면 Figma에서 그 파일 → 브랜치 만들기 → 이름 `Core 도우미` → 브랜치 URL을 채팅에 붙여넣는다.
- 그 밖의 문제는 Ken에게. 저장소 이슈로 남기면 다음 세션이 본다.
