# Core 도우미 — Figma 플러그인 (뼈대, 2026-09-18)

프로젝트 파일을 **분석 → 판별 → (새 Core면) 복제본을 Core로 정리 / (기존 Core면) Δ 화면을 골라 붙여 넣게** 도와주는 플러그인. Claude를 실행 중에 부르지 않는다. 판단은 전부 `rules.json`(규칙)과 `core-index/core-index.json`(Core 색인)으로 하고, 두 파일은 플러그인이 켜질 때 GitHub main에서 받아 온다 → **재설치 없이 규칙만 고치면 다음 실행부터 반영.**

## 파일

| 파일 | 역할 |
|---|---|
| `manifest.json` | 플러그인 정의. 네트워크는 `raw.githubusercontent.com`만 허용 |
| `rules.json` | 규칙 원본. 크기 클래스·마스터 페이지 규격·배치 숫자·설명 바 컴포넌트 키·삭제할 페이지·판별 임계값 |
| `code.js` | Figma 안에서 도는 쪽. 분석·판별·복제본 정리·붙여 넣은 화면 배치 |
| `ui.html` | 화면. 3단계(분석·판별 → 계획 → 실행) + "사례 남기기" |

## 설치 (개발 플러그인, 각자 노트북)

1. 이 저장소를 받는다(`git clone` 또는 ZIP 다운로드). `plugin/` 폴더가 있으면 된다.
2. Figma 데스크톱 앱 → 아무 디자인 파일 열기 → 메뉴 **Plugins → Development → Import plugin from manifest…** → `plugin/manifest.json` 선택.
3. 이후 **Plugins → Development → Core 도우미**로 실행. 규칙·색인은 실행마다 GitHub에서 내려받으니 저장소를 다시 받을 필요는 없다(플러그인 코드 자체가 바뀔 때만 다시 받는다 → Organization 비공개 게시로 넘어가면 그마저도 자동).

## 사용 흐름

### 새 Core (프로젝트 문서가 기존 Core에 안 들어맞을 때)

1. **프로젝트 파일**에서 플러그인 실행 → **분석** → 파일 종류(프로젝트/Core)·커버 정보·APP/WEB 크기별 후보 화면·수록 대조표·판별 후보가 나온다.
2. 크기별 후보가 틀리면 드롭다운으로 고친다. 판별 후보에서 **새 Core**를 고르고 **계획 저장**.
3. 안내대로 사람이 **File → Duplicate**(복제는 API로 못 한다) → 복제본 이름을 `[Core] ○○`로.
4. **복제본**에서 플러그인 실행 → 저장된 계획이 보이면 **복제본에 Core 만들기** → `🌏 마스터 파일` 페이지(링크 카드 + APP 3장 + WEB 4장, 설명 바 포함)를 만들고, 원본 화면과 대조(차이 0)한 뒤 작업 페이지(✅ Mobile / ✅ Web / 📏 운영 가이드 / ㄴ 로컬 컴포넌트)를 지운다. 로컬 컴포넌트 인스턴스는 먼저 분리(detach).
5. 남는 것: Cover / --- / 🌏 마스터 파일. Named version·파일 이동·색인 갱신은 사람이.

### 기존 Core 갱신

1. 프로젝트 파일에서 **분석** → 판별 후보에서 해당 Core를 고르고 **계획 저장**.
2. **Δ 화면 선택** → 바꿀 화면들이 선택된다 → ⌘C.
3. 그 Core 파일의 브랜치 **"Core 도우미"**를 열고 ⌘V → 플러그인 실행 → **붙여 넣은 화면 배치** → 마스터 규격 자리에 놓인다. (v1은 배치까지. 기존 화면과의 대조는 다음 단계)

## 규칙이 정교해지는 방식

- 애매한 사례(후보 점수가 안 갈림, 크기별 화면을 못 찾음, 이름 패턴이 새로움)는 플러그인이 **멈추고 사람이 고른다.** 고른 결과와 이유를 "사례 남기기"에 적으면 로그로 남는다.
- 그 사례를 Ken + Claude가 `rules.json`에 옮긴다(패턴 추가·임계값 조정·예외). 커밋 → main → 다음 실행부터 전 노트북에 반영.
- 플러그인 코드(`code.js`)는 규칙으로 못 푸는 새 동작이 필요할 때만 바뀐다.

## 게시 (나중, Organization 플랜)

Figma → Plugins → Development → Core 도우미 → **Publish** → 공개 범위 "Organization only". 이후 각자 노트북에서 Plugins에서 설치, 새 버전은 자동 반영. 게시 전에는 위 개발 플러그인 방식으로 시험한다.
