# Core 도우미 앱 아이콘 (2026-10-12)

맥락: "Core 파일 업데이트를 자동으로". 당근 시드가 '뿌리'를 로고로 삼은 것처럼, 우리 일 자체를 모양으로. 왓챠 핑크 그라데이션(#FF4B86 → #F0044F) 위 흰 기호.

- **A. C 루프 (현재 `../icon.png`)**: Core의 C가 스스로 도는 고리 = 자동 업데이트, 가운데 점 = 코어. 16px에서도 읽힘
- B. 파일 + 자동: 접힌 모서리 문서 안의 순환 화살표 — 가장 직관적이지만 흔함
- C. 코어 결: 겹겹이 쌓인 Core(나이테)를 바깥 고리가 갱신 — 작은 크기에서 뭉개짐

다시 그리기: `python3 gen.py` → SVG 3장. 바꾸려면 원하는 PNG(1024)를 `../icon.png`로 두고 `bash scripts/build-mac-app.sh`.
